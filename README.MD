Student: Oleksandr Myslyuk

Project Overview:
The main goal of this internship was to transform a complex Figma mockup into a fully functional, high-performance website. This project demonstrates skills in semantic HTML5, modern CSS architecture, and responsive design principles.

Key Features Implemented:
Fully Responsive Layout: Optimized for Mobile, Tablet, and Desktop screens using a mobile-first approach.
Interactive Components: Custom sliders and navigation for the "How-To" and "Specs" sections.
Adaptive Graphics: Implementation of art direction for images (different assets for different screen sizes) to ensure visual clarity.
Modern CSS: Usage of Flexbox and Grid for complex layouts, along with FontAwesome integration for iconography.

Tech Stack
HTML5: Semantic structure for SEO and accessibility.
CSS3: Custom properties, Flexbox, and Media Queries.
BEM Methodology: Clean and scalable naming convention for styles.
Figma: Accuracy in pixel-perfect translation from design to code.

Project Structure:
index.html — Main entry point.
assets/css/ — Stylesheets organized by modules.
assets/image/ — Optimized assets for all breakpoints.

Learning Outcomes:
During this practice, I mastered:
Handling multi-device adaptive layouts.
Creating comparison tables and interactive feature lists.
Organizing clean code that is easy to maintain and scale.
